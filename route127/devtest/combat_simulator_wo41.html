⚔ Route 127 · WO41 Combat Sandbox

DEVTEST developer tool · Standalone, experimental formula preview

Safe simulation, not live combat. This browser sandbox implements the key WO41 proposed formulas for hands-on testing. It is not the exact Node.js simulate.cjs harness or a deployment of the new combat engine. No game state, turns, inventory, or saves are read or modified.

Set up a fight

Matched-level enemies; no regional level rolls. Firearms use four-round default ammunition; automatic melee fallback when empty. Enemy damage is an experimental multiplier applied to enemy retaliation only (including enemy critical hits), not enemy HP or player damage. It is selected at the start of each fight. High-level bosses are included for scaling comparisons; this sandbox does not enforce story or level gates. Enemy count and gear can be changed before starting. This tests combat feel, not the full WO41 Monte Carlo measurements.
