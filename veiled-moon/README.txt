THE VEILED MOON ORACLE — WEB APP

Upload this entire folder to your existing GitHub Pages repository as: veiled-moon/
Then the app will be available at: https://lastlanternworkshop.com/veiled-moon/

Do not move the files out of this folder; paths are relative.

iPhone: open the URL in Safari → Share → Add to Home Screen.
Android: open in Chrome → menu → Add to Home screen / Install app.

The service worker caches the app assets after first load so the installed web app can continue working offline.
